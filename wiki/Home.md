## Quick Start

```bash
# 1. Clone the repo
git clone https://github.com/prasenjeet/roblox-game
cd roblox-game

# 2. Install Rojo (https://rojo.space), then serve:
rojo serve
```

Open Roblox Studio, install the **Rojo** plugin, click **Connect**, then press **Play**.
